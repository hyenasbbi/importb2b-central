# IMPORTB2B Central — Fase 5.4

## Inicio
- Ventas de hoy como bloque principal.
- Gráfico horario de ventas.
- Resumen mensual dentro del mismo bloque.
- Alertas accionables: pedidos web, dinero a liquidar, dinero a cobrar y stock crítico.
- Resumen compacto de stock y actividad reciente.
- Se eliminó Migración Kyte del Inicio.

## Finanzas 5.3 integradas
- Ventanas: Resumen, Movimientos, A liquidar, A cobrar, USDT/ARS, Resultados y Auditoría.
- Movimientos manuales: crear, editar y eliminar de forma segura.
- Movimientos automáticos: conservan trazabilidad con su origen.
- Liquidaciones: detalle de venta/cliente/productos cuando existe vínculo, liquidación a efectivo/transferencia y auditoría.
- Deudores: registro de cobros parciales, historial de pagos, saldo pendiente y trazabilidad.
- Go Cuotas: forma de pago real; las ventas generan automáticamente una liquidación a 25 días hábiles.
- Registros históricos de liquidaciones/deudas pueden vincularse a una venta existente.

## Backend
Las migraciones de Fase 5.3/5.4 fueron aplicadas directamente al Supabase del proyecto antes de generar este paquete.
