# IMPORTB2B Central — Fase 4

Fase 4 conecta el circuito comercial:

**Venta → Stock → Cliente → Finanzas**

## Módulos activos
- Inicio
- Vender / POS
- Productos / Stock
- Pedidos → Stock
- Clientes
- Finanzas
- Importador Kyte

## Deploy
Proyecto estático para Netlify. Subir el contenido a la raíz del repo `importb2b-central` y desplegar `main` con publish directory `.`.

El backend de Fase 4 ya fue aplicado al Supabase existente. No agregar `service_role` al frontend.
